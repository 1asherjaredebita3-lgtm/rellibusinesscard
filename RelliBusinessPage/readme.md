# Relli Ebita · Infoadvance digital card

A mobile-first static landing page for an NFC card. No build step or dependencies.

## Deploy to Netlify

1. Unzip the archive.
2. In Netlify, choose **Add new site → Deploy manually**.
3. Drag the `relli-ebita-card` folder into the deploy area.
4. Write the resulting HTTPS URL to the NFC card.

Edit `index.html` for content and links and `styles.css` for appearance. Update `assets/relli-ebita.vcf` if contacts change. The cutout portrait was supplied by the user. Business services and contact details came from infoadvance.com.ph. Save Contact uses public business contact details. Book a consultation opens an email request and does not confirm an appointment.
